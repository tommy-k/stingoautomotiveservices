# Stingo Automotive Services

> Professional mobile automotive diagnostics and repair serving Montgomery County & Bucks County, PA.

**Live Site:** [https://tommy-k.github.io/stingoautomotiveservices/](https://tommy-k.github.io/stingoautomotiveservices/)

## Features
- **Mobile First & Fully Responsive:** Built for fast mobile access from driveways, worksites, and roadside situations.
- **Service Catalog & Transparent Pricing:** Clear breakdown of diagnostics, brake service, battery/starter recovery, and routine maintenance.
- **Interactive Service Request:** Dispatch and quote intake with quick email and direct call actions.
- **Dynamic Theme Switcher:** Supports Dark, Light, and System OS preference modes.
- **Interactive FAQ Accordion:** Quick answers to common customer inquiries.
- **Continuous Deployment:** Automated GitHub Pages workflow powered by GitHub Actions.
